# Agent v2 acceptance contract

- Implement a separate LangChain/LangGraph agent in `agents/agent_v2`; preserve baseline behavior and existing corpus/retrieval tools.
- Public API: `AgentV2(answer_model, *, routing_model, domain_gate, planning_model=None, retriever=placeholder_retriever, coverage=None, max_retrieval_attempts=3, config=None)`. `invoke(question)` returns the existing BaselineResult contract. Dependencies are injected for offline testing. An optional planning model owns only planning after domain screening and discovery; omission or `None` keeps routing-model planning. Sufficiency stays on the routing model, final answers on the answer model, and planning failures propagate.
- Validate questions and retry limits before external calls. Propagate model, Jev, discovery and retrieval errors, never silently refuse on an API error.
- JevDomainGate(config, *, client=None) sends one HTTP POST to https://api.typesafe.ai/v1/systemone using Bearer TYPESAFE_API_KEY, finite timeout, model jev-latest, structured state containing the full question, and bundled Noul questions `report_question` and `financial_advice`. Read typed probabilities, not confidence. All wording and thresholds live in ood.py.
- Decision table: reject if report_question < 0.3 or financial_advice >= 0.7. Otherwise proceed, including uncertain probabilities. Unavailable companies/periods, report coverage and ambiguous financial-report questions are in domain. Network/HTTP/schema errors raise. Never send credentials in payloads or tracing metadata.
- AgentV2Config extends AgentConfig: model remains gpt-5-mini for answering; routing_model defaults gpt-5-nano; typesafe_model defaults jev-latest; typesafe_api_key is optional SecretStr but mandatory for constructing a real gate. Nonblank names; positive finite typesafe_timeout_seconds. Env names AGENT_V2_ROUTING_MODEL, TYPESAFE_MODEL, TYPESAFE_API_KEY, TYPESAFE_TIMEOUT_SECONDS.
- Out of domain: return bounded financial-report refusal, no OpenAI, coverage or retrieval calls. Trace the root, Jev model request/usage, nested models, tools and retrievals via LangChain boundaries. Missing enabled LangSmith configuration fails clearly.
- Use routing_model for one planning stage and context assessment; answer_model only for final answers. Before planning, discovery calls listed_companies then company_periods for every listed company. Structured plans restrict retrieval names to canonical company literals (Google=Alphabet, Facebook=Meta), and avoids report retrieval for coverage-only or verified wholly unavailable requests. Partial coverage must retrieve supported companies and disclose gaps. Never infer comparative evidence missing merely from missing standalone reports.
- Clarify essential missing intent: an unidentified company, broad results/performance without a metric or period, and unspecified growth without a measure/baseline. A year alone does not resolve a generic results request. For common bounded profit/earnings/margin ambiguity answer labeled alternatives. Prompts include the Amazon earnings 2025 example: revenue and net income, fiscal and calendar bases; combine identical periods only when evidence verifies matching dates. Known missing company/filing/period coverage instead returns `answered` with a short factual gap statement; do not offer external retrieval. Include the unavailable Uber FY2025 net-income routing example.
- Final answers normally use one or two factual sentences, with a compact list for multiple requested items. Include hypothetical few-shot examples for a fact, bounded profit alternatives, calculation, unavailable company/period, and bare-number output. Avoid preambles, repeated source lists, unsolicited offers and unnecessary fiscal-date dumps; preserve material dates, units, signs, precision, citations and evidence gaps.
- Financial source/page citations required unless a user asks for a specific formatting. Include a correct number-only example in prompts. Preserve evidence labels separately in result citations even when answer text omits citations. Obey requested precision/units/signs without postprocessing model output; scope, grounding and injection protections still apply.
- Chart/table prompts must match panel, series, row/column, period, units and accounting basis, distinguish annual/quarterly and total/segment. Never infer visual appearance from text alone or invent missing labels. Do not modify ETL or claim image/table fixes beyond evidence.
- Preserve the bounded refine/retrieve loop, accumulated evidence, per-company retrieval. Remove only exact repeated chunks (same source/text/metadata). On final allowed retrieval round skip the separate assessment call; answer prompt independently checks evidence and discloses gaps, with context_is_sufficient=false unless established.
- Use the separate v2 Promptfoo config/provider. The 3 November 2026 revision retains 114 case IDs but replaces five bounded ambiguity questions and narrows AMB02; preserve frozen historical exports and dataset snapshots. Versioned behavior cases accept bounded interpretations and exact formatting, including V210's margin comparison. Collect Jev tokens/calls/model and wall latency alongside OpenAI and embeddings; report Jev spend separately if pricing is unknown. Measured quality/latency/cost improvements require a live comparison, otherwise label unmeasured. Compare standalone domain-only classifiers to isolate screening RTT/cost rather than attributing the whole workflow difference to Jev.
